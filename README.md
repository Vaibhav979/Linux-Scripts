# 🚀 Bash Cloud Automation Toolkit

Production-ready Bash scripts for automating cloud server setup,
deployment, and maintenance.

## 📌 Features
- One-command EC2 bootstrap
- Automated Docker installation
- Secure SSH hardening
- Application deployment
- Database backups
- System monitoring

## ⚙️ Tech
Bash, Linux, AWS EC2, Docker, SSH

## 🚀 Usage

chmod +x *.sh

./ec2-setup.sh
./deploy.sh

## 🔒 Security
- SSH hardening
- Firewall rules
- Least privilege

## 📈 Use Case
Designed for rapid setup of backend services on fresh cloud instances.
